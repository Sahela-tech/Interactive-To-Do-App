# Interactive To-Do List Web Application 📝

A modern, responsive, and easy-to-use To-Do List application built with pure HTML5, Tailwind CSS, and Vanilla JavaScript.

## ✨ Features
* **Modern UI:** Glassmorphism card design styled with Tailwind CSS.
* **Task Filtering:** Filter tasks easily by All, Pending, and Completed states.
* **Data Persistence:** Integrated with Browser `LocalStorage` to persist tasks after refresh.
* **Responsive Design:** Completely mobile and desktop friendly.
* **Clean Action:** One-click clear button for completed tasks.

## 🛠️ Tech Stack
* **HTML5** - Page Structure
* **CSS3 & Tailwind CSS** - Styling
* **JavaScript (ES6)** - Application Logic & LocalStorage Handling

## 🚀 How to Run Locally
1. Clone this repository or download the source code.
2. Open the `index.html` file in any web browser.
