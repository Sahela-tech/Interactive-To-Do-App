A sleek, modern, and high-performance **Interactive To-Do List Application** designed for seamless daily task management. Built with a responsive **Glassmorphism UI** using **Tailwind CSS** and pure **Vanilla JavaScript**.

---

## ✨ Key Features

- 🎨 **Modern Glassmorphism Design:** Beautiful gradient background and clean backdrop-blur aesthetics.
- ⚡ **Real-time Task Tracking:** Easily add, complete, and delete tasks instantly.
- 🔍 **Smart Task Filtering:** Filter your tasks by **All**, **Pending**, and **Completed** statuses.
- 💾 **Data Persistence:** Integrated with Browser `LocalStorage` so your tasks remain safe even after refreshing or closing the browser.
- 📱 **Fully Responsive:** Perfectly optimized for Mobile, Tablet, and Desktop screens.
- 📊 **Dynamic Task Counter:** Displays real-time updates for pending and completed task metrics.
- 🧹 **Quick Clean:** One-click clear button to wipe out all completed tasks at once.

---

## 🛠️ Tech Stack

- **Frontend Structure:** HTML5
- **Styling & UI:** Tailwind CSS (via CDN) & Custom CSS
- **Logic & Functionality:** Vanilla JavaScript (ES6+)
- **Storage:** Web Browser LocalStorage API

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in any web browser.
